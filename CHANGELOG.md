# Changelog - Espelho Mágico Agrinho

## [1.0.0] - 2026-07-24

### Adicionado
- ✨ Interface gráfica completa com CustomTkinter
- 📷 Detecção de rosto em tempo real com MediaPipe
- 🎭 Sistema de personagens com suporte a PNG transparente
- 🎨 Gerenciador de cenários dinâmicos
- ✨ Sistema de efeitos visuais (folhas, sementes, flores, brilho)
- 📸 Captura de fotos com moldura personalizada
- 🔊 Gerenciador de áudio com Pygame
- ⚙️ Sistema de configurações em JSON
- 🎮 Modo fullscreen
- 💾 Galeria automática de fotos capturadas
- 📝 Documentação completa (README, INSTALL, USAGE, TECNICO)
- 🔨 Script para gerar executável Windows com PyInstaller

### Características
- Tema Agrinho com cores verde, amarelo e azul
- Preview de câmera em tempo real
- Contagem regressiva para captura
- Efeitos ativados/desativados dinamicamente
- Sons ativados/desativados dinamicamente
- Detecção automática de rosto centralizado
- Moldura personalizada com texto
- Armazenamento local de fotos

### Estrutura
- 12 módulos Python bem organizados
- 8 pastas para assets (personagens, cenários, sons, etc)
- Sistema modular e extensível
- Fácil customização sem modificar código

---

## Notas de Versão

### Conhecidos Limitações
- Suporte a um rosto por vez (múltiplos rostos podem ser adicionados)
- Moldura estática (texto pré-definido)
- Sem integração com redes sociais
- Sem modo portrait (apenas landscape)
