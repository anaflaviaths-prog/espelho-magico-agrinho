# Pasta de Assets

## Arquivos esperados

### logo.png
- **Dimensões:** 200x200 ou 256x256 pixels
- **Formato:** PNG com fundo transparente
- **Uso:** Logo na interface do aplicativo
- **Peso:** até 500 KB

### icone.ico
- **Dimensões:** 256x256 pixels
- **Formato:** ICO ou ICON
- **Uso:** Ícone na barra de tarefas do Windows
- **Peso:** até 1 MB
- **Criação:** Converta PNG para ICO usando ferramentas online

## Como gerar ICO a partir de PNG:

1. Acesse: https://convertio.co/pt/png-ico/
2. Faça upload da imagem PNG
3. Defina como 256x256 pixels
4. Baixe o arquivo .ico
5. Salve como `icone.ico` aqui

## Alternativa:

Use ferramentas locais como:
- GIMP (exportar como .ico)
- ImageMagick (converter via linha de comando)
- Python PIL (script de conversão)
