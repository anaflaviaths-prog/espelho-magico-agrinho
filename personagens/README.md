# Pasta de Personagens

## Como adicionar personagens

1. Prepare imagens PNG com **fundo transparente**
2. Recomendado: 500x500 pixels
3. Salve em formato PNG-24 com alfa
4. Coloque nesta pasta
5. Aplicativo carrega automaticamente

## Personagens de exemplo esperados:

- `menina.png` - Personagem feminino
- `menino.png` - Personagem masculino  
- `professor.png` - Educador
- `vovo.png` - Avó
- `agricultor.png` - Agricultor
- `mascote.png` - Mascote agrinho

## Formatos aceitos:

- **PNG** ✅ (com transparência)
- **Dimensões:** 300x300 até 800x800 pixels
- **Cores:** RGB ou RGBA
- **Peso:** até 5 MB por arquivo
