# Pasta de Cenários

## Como adicionar cenários

1. Prepare imagens de alta resolução (1920x1080 ou maior)
2. Formatos: JPG ou PNG
3. Coloque nesta pasta
4. Aplicativo carrega automaticamente

## Cenários de exemplo esperados:

- `fazenda.jpg` - Cena de fazenda com plantas
- `escola.jpg` - Cena de escola/sala de aula
- `horta.jpg` - Cena de horta/plantação
- `natureza.jpg` - Cena de natureza/floresta
- `campo.jpg` - Cena de campo aberto
- `mercado.jpg` - Cena de feira/mercado

## Formatos aceitos:

- **JPG** ✅ (melhor compressão)
- **PNG** ✅ (maior qualidade)
- **Dimensões:** 1280x720 até 3840x2160 pixels
- **Peso:** até 20 MB por arquivo

## Dica:

Use imagens que representem temas agrícolas para manter a coerência com a Feira Agrinho!
