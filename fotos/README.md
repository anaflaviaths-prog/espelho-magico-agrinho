# Pasta de Fotos Capturadas

Esta pasta armazena automaticamente todas as fotos capturadas pelo Espelho Mágico Agrinho.

## Nomenclatura de arquivos:

- **Formato:** `AAAA-MM-DD_HH-MM-SS.png`
- **Exemplo:** `2026-07-24_14-35-22.png`

## Características das fotos:

- **Formato:** PNG (sem perda de qualidade)
- **Resolução:** Mesma da câmera configurada (ex: 1280x720)
- **Tamanho:** ~500 KB a 2 MB por foto
- **Moldura:** Com moldura personalizada Agrinho
- **Armazenamento:** Local (computador do usuário)

## Gerenciamento:

- Crie subpastas por data/evento
- Faça backup regularmente
- Exclua fotos não desejadas manualmente
- Sem sincronização em nuvem (privacidade garantida)

## Nota de Privacidade:

Todas as fotos são armazenadas **localmente no seu computador**. Nenhuma foto é enviada para servidores externos ou redes sociais sem sua autorização explícita.
