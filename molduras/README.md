# Pasta de Molduras

## Como adicionar molduras

1. Prepare imagens PNG com **fundo transparente**
2. Dimensões: mesma resolução da câmera (1280x720)
3. Deixe espaço no centro para a foto
4. Coloque nesta pasta
5. Aplicativo carrega automaticamente

## Molduras de exemplo esperadas:

- `moldura_agrinho.png` - Moldura tema Agrinho
- `moldura_fazenda.png` - Moldura com tema fazenda
- `moldura_flores.png` - Moldura com flores
- `moldura_verde.png` - Moldura verde (natureza)
- `moldura_escolar.png` - Moldura com tema escolar

## Formatos aceitos:

- **PNG** ✅ (com transparência)
- **Dimensões:** 1280x720 pixels (padrão)
- **Cores:** RGB ou RGBA
- **Peso:** até 10 MB por arquivo

## Como criar:

1. Use Photoshop, GIMP ou Canva
2. Crie um design decorativo nas bordas
3. Deixe um retângulo central transparente
4. Exporte como PNG-24 com transparência
5. Salve aqui nesta pasta
