# Pasta de Fontes

## Como adicionar fontes

1. Coloque arquivos TTF ou OTF aqui
2. Sistema operacional fornece fontes padrão
3. Use fontes adicionais para customização
4. Aplicativo usa Tkinter default se não encontrar

## Fonte recomendada:

- `Arial.ttf` - Fonte padrão legível
- `Comic Sans MS.ttf` - Fonte divertida para crianças
- `Font Awesome.ttf` - Ícones (opcional)

## Formatos aceitos:

- **TTF** ✅ (TrueType Font)
- **OTF** ✅ (OpenType Font)
- **Peso:** até 2 MB por arquivo

## Dica:

Fontes alegres e coloridas combinam melhor com o tema infantil/agrinho!
