# Pasta de Sons

## Como adicionar sons

1. Prepare arquivos de áudio em:
   - WAV (melhor qualidade)
   - MP3 (mais comprimido)
   - OGG (formato aberto)
2. Taxa de amostragem: 44.1 kHz ou 48 kHz
3. Canais: Mono ou Stereo
4. Coloque nesta pasta
5. Aplicativo carrega automaticamente

## Sons de exemplo esperados:

- `click.wav` - Som de clique/botão
- `foto.wav` - Som de câmera/captura
- `sucesso.wav` - Som de sucesso
- `error.wav` - Som de erro
- `musica.mp3` - Música de fundo
- `efeito_folhas.wav` - Efeito de folhas caindo
- `efeito_sementes.wav` - Efeito de sementes

## Formatos aceitos:

- **WAV** ✅ (sem compressão)
- **MP3** ✅ (comprimido)
- **OGG** ✅ (formato aberto)
- **Duração:** até 30 segundos por som
- **Peso:** até 5 MB por arquivo

## Dica:

Use sons relacionados à natureza e agricultura para manter a temática!
